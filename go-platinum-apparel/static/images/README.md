# Luxury Stock Pack

This folder contains 50 luxury-themed images organized for use in a demo or test ecommerce-style website.

## Categories
- watches
- jewelry
- suits
- handbags
- perfume
- bullion

## Included metadata
- `claude_manifest.json` at the root for straightforward ingestion by Claude Code
- `descriptions/manifest.json` with full metadata
- `descriptions/manifest.csv` for spreadsheet-friendly review

## Suggested uses
These images were selected to cover:
- product cards
- gallery grids
- hero banners
- promo/ad tiles
- category headers
- craftsmanship/detail sections

## Important note
Some images depict recognizable branded products or trademarked product designs. For a mockup, prototype, classroom project, or internal test site this is generally the intended use case. For a public production site, review trademark, endorsement, and marketplace/platform policies before using brand-identifiable imagery commercially.
